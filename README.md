During this lab session, we used VS Code to build a multi-screen React Native registration app using Expo Router. The application features a registration screen that captures user inputs (like name, email, and birth year) using TextInput and useState, while performing basic form validation such as password matching. We successfully implemented data transfer between screens, passing the user's details and a dynamically calculated age to a review screen using useLocalSearchParams. Finally, we utilized the navigation stack (router.back) to allow users to easily return and edit their information, and added conditional logic to ensure the user is at least 18 years old before proceeding to the final success screen. All screenshots of the working application are saved in the Output_Screens folder.
